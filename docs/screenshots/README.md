# Hero screenshots

Drop hero images here using these exact filenames so the top-level
`README.md` picks them up:

| File              | Suggested view                                 |
|-------------------|------------------------------------------------|
| `hero.png`        | The default sunset preset, slightly elevated camera, both boats and an island in view. 1600x900 ideal. |
| `tropical.png`    | `?preset=tropical` -- shallow turquoise water, see-through to the sand floor. |
| `storm.png`       | `?preset=storm` -- choppy waves, splash spray, lots of foam. |
| `underwater.png`  | Camera dipped below the surface, looking up at the underside of waves + fish school. |
| `wake.png`        | Close-up behind a moving boat showing the interactive-water bow wave + auto wake foam. |

Capture from the live demo (https://NA-DEGEN-GIRL.github.io/wave-three-js/)
or from `npm run dev` locally. Browser print-screen + crop to ~1600x900 is
fine; PNG keeps the foam detail crisp.
